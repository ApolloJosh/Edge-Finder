# Gridiron Edge exports

You don't need this folder on NFL game days: Edge Finder runs Gridiron Edge
itself about 4 hours before the first kickoff.

Use it when you've rescanned Gridiron Edge after late news and want that read
on the board right away:

1. In Gridiron Edge, click **⇩ Export for Edge Finder** (saves
   `gridiron-edge-2026-wkNN.json` to Downloads).
2. Here on GitHub: **Add file → Upload files**, drop the file in, **Commit changes**.
3. The board rebuilds with it in a couple of minutes.
